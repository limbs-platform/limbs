# Security Policy

## Supported Versions

Only the latest release of LIMBS receives security fixes.

## Reporting a Vulnerability

Please do not open a public issue for security problems.

Report privately via GitHub's "Report a vulnerability" button
(Security tab of this repository).

Include a description, steps to reproduce, and the affected version.

## What to Expect

- Acknowledgement within 3 business days.
- A status update within 14 days.
- Credit in the release notes if you want it.

Please give us reasonable time to fix the issue before disclosing it publicly.
